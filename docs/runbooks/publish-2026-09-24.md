## If it goes wrong

- **Before step 10's real upload**, nothing public has moved. Restore the local tree from
  `$day\web_export.tar` and the metrics store from `$day\analytics.db`, and stop.
- **After it**, R2 holds the new bytes. Restoring the tar and running
  `--upload-only` with **no** `--refreshed` re-sends the old bytes for every changed key and
  deletes nothing. Keys that were ADDED (`lab/`, `nfl/sources.json`) stay served until a run
  that declares their prefix no longer produces them - that is the uploader's rule, not a gap.
